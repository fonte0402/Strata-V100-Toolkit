# Strata 可移植工具箱

本仓库提供 Windows/Python 启动配置生成器、带服务归属核验的启动/停止工具、离线资格检查，以及可单独校验的 API 与 v138 引擎源码补丁。可迁到任意目录（含空格），再显式填写 Python、API 根目录、引擎程序、GPU UUID、端口和外置资产路径。

开始前请阅读英文主说明 [README.md](README.md) 的“Generate a service setup”。把示例里的 `<ROOT>`、`<RUNTIME_ROOT>`、`<PYTHON_EXE>` 换成目标机器的路径。生成配置会同时写出 `start.ps1` 与 `stop.ps1`；状态、日志和数据库放在运行目录。`show-command` 可离线预览计划，不会检查 GPU、占用端口或启动进程。

后台任务必须显式提供工具仓库以外的受保护 JSON 文件路径（包含 `api_key` 字段）；密钥只在运行时从该文件读取，不复制进仓库或启动参数。GPU UUID 和端口没有本机默认值。停止操作先核对 PID 创建时间、可执行文件指纹、服务进程树和端口归属。

质量任务是合成夹具，不包含历史运行输出、原始用户日志或模型资产。长上下文校准必须传入实际服务使用的 tokenizer 数据目录与实现脚本。

API 补丁只应用于 metadata 中记录的精确 v31-era Git 基底；v138 引擎补丁以独立的原始 v0.1.38 tar SHA 为基底。源码补丁校验不会启动模型、使用 GPU 或证明外置二进制由这些源码构建。
