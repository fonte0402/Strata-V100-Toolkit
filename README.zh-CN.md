# Strata V100 Toolkit

[English](README.md) · [测试数据](docs/BENCHMARKS.md) · [上游 Strata](https://github.com/Niko1221/Strata)

**在单张 Tesla V100 32GB 上运行 Qwen3.8-Flash-Next：MTP 加速、8K–256K 上下文、Vision、OpenAI API，以及 Windows 网页运维。**

本项目记录这台 **i9-13900F + DDR4 + PCIe Gen3 x4 + Windows** 机器的实际测试，并整理可移植的服务工具与源码补丁。推理引擎来自 Strata；当前基线是 v0.1.38，v0.1.39 正在受控验收。

## 实测表现

### 五档上下文矩阵

历史 v0.1.38 测试，原版 GSQ-RCO IQ3_XXS + MTP T=3，自动 expert cache：

| 配置上下文 | Decode（token/s） | Expert cache 槽数 |
|---|---:|---:|
| 8K | **91.4** | 15,375 |
| 32K | **88.3** | 14,927 |
| 64K | **84.5** | 14,403 |
| 128K | **80.8** | 13,317 |
| 256K · RoPE 外推 | **70.9** | 11,191 |

口径：medium 思考档、512 个生成 token、同类请求顺序第二次重复；temperature 1.0 / top_p 0.95 / top_k 20 / seed 42。生成 token 可包含思考；这是热缓存固定输出测试，不能当作所有真实请求的稳定速度。256K 是外推档。原始选定字段已脱敏为 [CSV](docs/context-matrix.csv)。

## 已实现的能力

- **Text / Vision 配置**：8K、32K、64K、128K、256K；上下文与视觉能力在启动时固定。
- **请求级 Thinking 与 ESP**：思考强度由客户端选择；ESP 可在启动配置中加载、通过网页或单次 API 请求切换。显式请求参数优先于共享默认设置。
- **网页运维**：Chat、Sampling 共享默认设置、Monitor，以及 **Shutdown**。
- **持久 token 用量**：本次运行、今日、累计；跨重启保存，初始输入与内部续写缓存分别记录。
- **可移植服务管理**：支持迁移目录、外置资产和认证文件；启停核对进程创建时间、指纹与端口归属。

ESP 为实验功能；本项目公开实测，不把它视为零质量影响的保证。
